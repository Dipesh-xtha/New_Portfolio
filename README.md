# Dipesh Shrestha portfolio

Live site: https://dipeshshrestha69.com.np

The editable Next.js project is in [`nextjs/`](nextjs/). The repository root contains its static export for GitHub Pages. Do not hand-edit generated HTML or `_next/` files.

For updates, edit `nextjs/`, run its build and verification, then run `npm run publish:files` from that folder. Review, commit and push the changed source and generated files together. See [`nextjs/README.md`](nextjs/README.md) for the complete release and rollback steps.

GitHub Pages configuration: deploy from the `main` branch, `/ (root)`, custom domain `dipeshshrestha69.com.np`, HTTPS enabled.
